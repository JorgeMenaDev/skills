# seo-growth-workspace v5.1.0 — operating-policy ratification

Release run for the values ratified in `JorgeMenaDev/matias#118`. The canonical machine record is `gate-results-5.1.0.json`; this document renders the decision and validation evidence but is not an alternate source of truth.

## Scope

- Added one canonical operating-policy reference for SEO Stage, cadence, frontier bounds, coverage age, typed gates and wakes, SEO Ship capacity, priorities, measurement timing, and the no-concurrent-mutation assumption.
- Removed the per-site lease contract, helper, reserved state filename, and every active runtime reference. No replacement lock, TTL, heartbeat, fencing, dispatcher, or coordination mechanism was added.
- Made `cadence-status.mjs` derive coverage expiry from the fixed rung map and honor persisted/final retry escalation, so stale loop values cannot override the new policy.
- Preserved the optional schema-1 loop state and its crash-retryable fingerprint reconciliation.
- Marked historical criteria C106-09 and C106-15 as superseded rather than rewriting their original requirements.
- Bumped the portable skill and bootstrap stamp from 5.0.1 to 5.1.0.

## Locked values

- Stage: monthly weakest-signal classification; Unknown uses Early defaults; thresholds are 100/1 for Growth and 1,000/3 in each of two consecutive 30-day periods for Mature.
- SEO Ship: one new or materially revised canonical public URL; rolling seven-day caps are 2 Unknown/Early, 4 Growth, and 7 Mature.
- Frontier: seven-day rung cooldown, ten candidates, one Ready ticket, top three rejected candidates retained; coverage ages B 14, A/C/E/F/J 30, D 60, G/H/I 90 days.
- Gates: only `dependency`, `access`, `browser-slot`, and `human-approval`, with their event/date wake and escalation timings.
- Cadence: stage-based GSC, universal monthly crawl/indexing/CWV/CRO, quarterly refresh/strategy, and next-day then three-days-later execution retries.
- Priorities: cadence P4/reporting and measurement P3/measurement; due-ness never promotes.
- Measurement: first check at 28 days; inconclusive recheck at 14 days.
