## Autoreview

Round 1 (codex gpt-5.6-sol, branch diff vs origin/main): 2 findings, both real, both fixed before merge — [P1] shared-clone concurrent recaps are git-unsafe (repository-wide autostash rebase races another run's uncommitted work) → own clone/worktree per concurrent run or serialized git phases; [P2] non-keep classification undefined when the creating version is unknowable → `version-driven` by convention, reason-noted. Round 2: 1 finding, real — git-phase-only serialization is still unsafe (an autostash rebase can stash/restore files underneath a sibling run still writing its workspace files) → serialization widened to the entire run. Round 3: 1 finding, real — a write-through-push window still permits a read-versus-rebase race (a sibling's rebase invalidates a run mid-read, producing conclusions from a stale snapshot) → shared-tree overlap prohibited outright; the serialization unit is first workspace read through push. Round 4: 2 findings, both real — [P2] "max-age delta alone does not stale a row" was overbroad (a shortened policy still expires rows through ordinary `observedAt +` current-policy expiry; split method invalidation from ordinary expiry) and [P2] in-place mirror repair contradicted the immutable-ledger confirmation (resolved by defining `observedAt`/`artifact` as history and the mirror + additive annotations as the only permitted in-place ledger mutations). Gate artifact re-reported and rebound after each round's fixes.
