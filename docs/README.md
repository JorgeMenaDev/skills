# Documentation and templates

Reusable engineering guidance and supporting material live here.

[AGENTS.md](./AGENTS.md) is a template for a coding agent's repository instructions. Copy it to your repository's root and adapt it to your workflow. It covers design, scoped changes, verification, TypeScript, Git, permissions, delegation, and communication.

Add repository-specific commands and constraints where they help an agent make decisions. Keep project overviews in your README and detailed procedures in separate documents.

[prompts/](./prompts/) holds reusable prompts that are not skills, such as [excalidraw-spec-wireframe.md](./prompts/excalidraw-spec-wireframe.md), which turns a multi-phase spec into an Excalidraw wireframe and data model board.
