# Informe de feedback de producto

Esta skill ayuda a una persona fundadora a registrar problemas e ideas mientras prueba un producto web o móvil. No hace las pruebas por su cuenta: acompaña la sesión, hace una sola pregunta cuando falta información y mantiene un PDF profesional siempre actualizado.

## Qué hace

- Puedes usarla durante unos minutos o varias horas, cerrar el agente y continuar otro día.
- Al comenzar, permite continuar un informe pendiente o crear uno nuevo.
- Cada informe corresponde a una misión concreta, por ejemplo: `Nexonet - Flujo de nueva recepción - julio 2026`.
- Puedes explicar lo que viste con tus propias palabras. No necesitas completar formularios ni usar vocabulario técnico.
- Los hallazgos se guardan como **Problema** o **Idea**.
- Para problemas visuales pide una captura; para problemas de flujo acepta un video corto y usa una imagen representativa dentro del PDF.
- Protege información sensible y puede añadir una flecha o recuadro para señalar el problema.
- Guarda cada hallazgo inmediatamente y actualiza el PDF.
- Puedes marcar un informe como completo y volver a abrirlo más adelante.

## Cómo usarla

Después de instalarla, abre Codex, Claude Code o Hermes y escribe algo natural, por ejemplo:

> Quiero crear un informe de feedback mientras pruebo Nexonet.

La primera vez te preguntará dónde guardar los informes. Puedes aceptar la recomendación:

```text
~/Documents/Product Reports/
```

Después solo describe lo que encuentres:

> Estoy creando una recepción. Cuando termino el segundo paso aparece el tercero durante un segundo y luego se cierra todo.

El agente pedirá únicamente la información que falte, solicitará una captura o video cuando corresponda y guardará el hallazgo. Puedes continuar con frases como:

> Tengo otro problema.

> Añade esta captura.

> Cambia el hallazgo anterior: no ocurre siempre, ocurrió dos de tres veces.

> Pausamos por hoy.

> Quiero continuar el informe de Nexonet.

> El informe está terminado.

El archivo principal que debes compartir es `REPORT.pdf`. Los originales y el estado editable permanecen en tu carpeta local; si el equipo necesita ver la secuencia completa, puedes enviar también el video guardado junto al informe.

## Lo que no necesitas hacer

- No necesitas saber qué es un ticket, una especificación o Wayfinder.
- No necesitas proponer una solución técnica.
- No necesitas terminar el informe en una sola sesión.
- No necesitas clasificar la prioridad salvo que el impacto sea ambiguo.
